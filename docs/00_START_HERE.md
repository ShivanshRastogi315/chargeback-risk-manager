# AI Risk Manager — Chargeback Evidence Automation
## Project Overview & Ground Rules

Read this file first in every new session. Only open the other docs if the current phase's task actually requires their detail.

---

### Project Summary
AI Risk Manager is a defense-only automated chargeback representment system designed for merchants (particularly mid-size and cold-start merchants) to systematically dispute illegitimate first-party fraud claims. Instead of outputting an opaque win-probability, the platform evaluates dispute evidence criterion-by-criterion against Visa CE3.0 and Mastercard First-Party Trust standards, computes calibrated ROI on whether contesting is commercially viable (even with thin transaction history), and synthesizes auditable, machine-verifiable representment packets. What makes it novel is its public reproducible benchmark, conformal-prediction escalation with error guarantees, rule-version drift detection, and strict constraint that 100% of narrative claims cite verifiable transaction fields.

---

### Non-Negotiable Constraints
These constraints must **never** be violated in any session:
- **Defense-Only:** Never generate functionality that fabricates evidence, falsifies transaction records, or helps construct a fraudulent chargeback or representment. All scorers, narrative engines, and rules only summarize and cite real transaction facts.
- **Honest Currency Metrics:** Every module and evaluation run must report honest metrics including false-positive and false-negative costs measured in currency (₹), count-based win rate, and amount-weighted win rate—never relying on isolated or misleading accuracy numbers.
- **Auditable Citation Tags:** Every claim generated by the narrative generator must carry an explicit citation tag resolving to a real input field in the transaction record—no exceptions, ungrounded claims, or free-floating statements.
